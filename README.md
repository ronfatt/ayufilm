# DIRECTOR OS (AI 影视制作工作台)

专业电影制作公司与 AI 导演团队共同使用的影视制作工作台。

暂名 **「DIRECTOR OS」**（可在系统设置中自由配置品牌名称）。

---

## 一、产品定位与核心能力

DIRECTOR OS 以**镜头为核心（Shot-Centric）**，将故事剧本、视觉设定、制作任务、素材版本、导演审核与剪辑交接无缝连接。

平台支持 3 种主流制作路径及在同一项目、同一场戏中的混合编排：
1. **全 AI 生成短片 (Full AI)**：参考资产锁定 → 起始关键帧 → 视频提示词驱动 → 结果上传与审核。
2. **真人实拍 (Live Action)**：拍摄技术指标 → 原始机位素材 → 现场 Take 记录 (导演选定标记) → 审核。
3. **真人实拍 + AI 深度改造 (Live + AI)**：实拍素材 → 指定改变区域与目标 → 明确保留表演与运镜 → 跟踪/抠像/光线匹配合成 → 审核。
4. **混合制作 (Hybrid)**：同一项目中自由混用上述制作路径。

## 二、运行与启动方式

### 运行环境
- Node.js: `>= 18.0.0`
- 浏览器: Chrome, Safari, Edge, Firefox（支持现代 IndexedDB）

### 启动命令
```bash
# 1. 安装依赖 (如果尚未安装)
npm install

# 2. 启动开发服务器
npm run dev
# 或直接通过 Node 启动
npm run dev:direct

# 3. 生产模式构建与启动
npm run build
npm run start
# 或直接运行
npm run build:direct
npm run start:direct
```
浏览器打开：`http://localhost:3000`（或控制台提示端口，如 `http://localhost:3005`）。

## 三、信息架构与主要功能

### 1. 全局导航与配置
- **品牌名称可配置**：点击右上角设置，可自定义平台品牌名称（如 `Ayu Film Maker / DIRECTOR OS`），全局响应式更新。
- **本地演示模式**：
  - 结构化数据全量持久化在浏览器的 **IndexedDB**（数据库 `director_os_db`）。
  - 图片与视频作为 **二进制 Blob** 原生存入 IndexedDB，不使用 localStorage 编码，支持大体积视频稳定暂存。
  - 明确标注「本地演示模式，数据保存在当前浏览器」。
  - 演示成员切换（导演、AI 视觉总监、摄影指导、制片人、剪辑指导）仅改变当前任务视角，不伪装多人同步。
- **项目 JSON 导入与导出**：一键导出项目全量工程，支持导入并执行校验。

### 2. 项目总览 (Overview)
解答导演与制片人进入系统后的 4 个核心问题：
1. **我正在制作什么？** 显示项目类型、一句话故事、目标片长、画幅、主语言、制作方式与视觉方向。
2. **哪些内容需要我确认？** 统计待审核（`ready_for_review`）与需修改（`changes_requested`）镜头，提供直达入口。
3. **当前制作卡在哪里？** 动态抓取阻塞任务（`blocked`），显示具体依赖原因。
4. **下一步做什么？** 智能生成下一步操作建议（如优先审阅关键镜头、解除阻塞、运行导演核验）。
- **真实进度驱动**：进度条严格来自镜头与任务实际状态，非装饰数字；点击进度条色块可直达对应镜头过滤。

### 3. 故事工作区 (Story & Scenes)
- 剧本实时编辑与多版本存档。
- **拆解剧本 (规则解析)**：采用明确标注的基础规则解析（识别场次标头、日夜时间、地点、登场角色与动作），提供人工复核对话框，严禁虚标为 AI 理解。
- 场次管理：每场记录地点、日夜（`DAY / NIGHT`）、登场人物、动作梗概、对白重点及**情绪目的 (Emotional Goal)**。
- 场次与镜头双向关联。剧本更新后，提示关联镜头需复核，绝不静默覆盖已有分镜。

### 4. 视觉设定库 (Visual Bible)
支持四种资产类型：
- **角色 (Character)**：姓名、身份、年龄、外形特征、发型、服装版本（支持战损/日常多版本）、声音备注。
- **场景 (Scene)**：名称、空间说明、出入口、主要光源、日夜与状态版本。
- **道具 (Prop)**：名称、归属人物、关键展开状态。
- **视觉风格 (Visual Style)**：色彩基调、对比度指南、光影风格、摄影参考、画幅与禁止事项。
- **版本锁定与受影响镜头排查**：
  - 修改已被镜头引用的资产时，自动检测受影响镜头列表。
  - 提供两个安全选项：
    - **策略 1（默认）：仅建立新版本**（原引用镜头保持旧设定，防止已批准镜头被破坏）。
    - **策略 2：将指定镜头更新到新版本**。

### 5. 镜头工作台 (Shot Workbench) —— 核心中枢
- **界面布局**：
  - **左侧**：场次与镜头树状列表，支持状态筛选、制作方式筛选、实时搜索。
  - **中央**：大画幅预览（支持 16:9 / 9:16 / 1:1 画幅切换，适应容器/充满画面切换）。
    - 素材版本切换器与「当前采用版本」标记（每个镜头至多一个采用版本，已批准必须绑定具体素材）。
    - 视频播放器与**时间点评论 (Timecoded Comments)**：播放视频时添加意见，点击评论时间戳直接定位到对应秒数。
    - **双版本并排对比 (Side-by-Side Comparison)**：方便对比新旧渲染或实拍与合成版本。
  - **右侧**：镜头基本字段 + 可折叠展开的 **「导演细节 (Cinematography)」** 面板：
    - 景别 (Shot Size)、机位角度 (Camera Angle)、焦段参考 (Lens)、构图与主体位置、人物调度、视线方向、运动方向、轴线所在侧、动作起止、灯光方向、情绪强度 (1-10)、入出镜状态、接戏衔接、特效与拍摄备注。
    - 未知参数允许留空，绝不胡乱编造。
  - **底部**：可收起的连续镜头时间线预演条（Timeline Strip）。
- **三种视图实时同步共享同一份数据**：
  - 分镜卡片视图 (Storyboard Cards)
  - 可编辑表格视图 (Editable Table)
  - 镜头顺序预演视图 (Sequence Preview)
- **不可变内部 ID 与重排**：内部 ID 恒定，重排镜头编号不影响素材与评论关联；删除镜头提供一键撤销（Undo）。

### 6. 提示词工作区 (Prompts)
- 根据镜头机位、灯光、动作与引用的视觉资产版本，自动组装可编辑的提示词：
  - **静态关键帧提示词 (Static Keyframe)**：单一可见瞬间、光影、构图与胶片质感。
  - **动态视频提示词 (Dynamic Video)**：运镜顺序、主体动作起点终点、环境变化。
  - **实拍改造说明 (Hybrid Directives)**：明确说明「需改变什么」、「必须保留什么」、「跟踪抠像要求」。
- 提供中英文对照、一键复制、重新生成、平台标签（如 `Kling 1.5`, `Runway Gen-3`）。
- 未接入翻译模型时诚实提示，不假装机器翻译。

### 7. 导演连续性核验面板 (Director Audit)
- 基于结构化字段的可解释规则分析：
  - 连续 3 个相似景别提示
  - 连续 3 个相同运镜提示
  - 镜头累计时长超出项目总目标
  - 缺少叙事目的提示
  - 缺少视觉资产绑定提示
  - 同场戏中角色服装版本不一致
  - 相邻镜头人物运动方向突然反转（疑似越轴）
  - 任务尚未完成却标记为已批准
- 每条提示展示：**涉及镜头、触发原因、建议动作**。
- 支持导演标记 **「有意安排」** 并录入艺术创作理由，消除虚假误报。
- 人工创作核验清单：叙事与戏剧弧、视听覆盖与空间轴线、视觉风格与制作可行性。

### 8. 制作与任务 (Production Tasks)
- 支持看板 (Kanban) 与列表 (List) 切换。
- 支持执行人筛选、截止日期、关联镜头。
- 阻塞原因标注与依赖管理。

### 9. 成片与交付 (Delivery)
- **顺序预演播放器**：按镜头设定时长顺序播放，支持暂停、上一镜、下一镜，明确标注为制作预演。
- **交付自检清单**：统计未定板镜头与缺失素材镜头。
- **四类工业导出**：
  1. **剪辑交接表 (CSV)**：剪辑顺序、镜头号、文件名、时长、对白、实拍/AI改造指示、剪辑衔接备注。
  2. **分镜清单 (CSV)**：RFC 4180 标准，带 UTF-8 BOM，彻底解决 Excel/WPS 中文乱码。
  3. **可打印分镜排版**：调用系统打印生成纸质分镜手册。
  4. **项目工程全量 JSON**：备份与异地导入。

## 四、官方演示项目：《机密节点 / NOD RAHSIA》

平台内置了完整预置演示项目，包含：
- **片名**：《机密节点 / NOD RAHSIA》
- **目标时长**：120 秒（约 2 分钟）
- **画幅**：16:9
- **语言**：Bahasa Melayu（马来语对白）/ 中文字幕
- **镜头数量**：**完整 27 个镜头**，横跨 4 场戏：
  - 场次 1：地下机房潜入与拷贝数据（全 AI 与实拍+AI）
  - 场次 2：雨夜狭窄后巷搏斗与夺车（实拍 Silat 格斗与实拍+AI 弹孔/水花）
  - 场次 3：工业区高架狂飙与无人机激光追逐（全 AI 与实拍机车压弯）
  - 场次 4：废弃店屋解密与异次元空间节点撕裂（全 AI 与实拍+AI 黑洞光环合成）
- **视觉设定资产**：主角 Razak（多套服装版本）、反派 Malik、数据筒核心道具、机房与雨巷场景、Rainy Cyber-Noir 视觉风格。
- **演示数据重置**：顶部下拉菜单随时一键重置，绝不覆盖用户自建项目。

4. **多人实时协同与鉴权**：实现 `ICollaborationService` 与 `IAuthService`（接入 WebSocket / Yjs / Supabase Realtime 及 JWT 角色权限控制）。
